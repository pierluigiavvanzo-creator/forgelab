# Machine Contracts

All timestamps are UTC ISO 8601 strings. IDs are non-empty strings generated by
the control plane. Enumerations are serialized using their uppercase values.

`AgentTask` declares role, objective, path scope, acceptance criteria, allowed
tools, limits, and escalation conditions. `AgentResult` contains status,
summary, changed artifacts, evidence references, findings, assumptions, and a
next action.

Evidence is external to model prose. Each record identifies its check type,
tool or command, exit status, summary, and optional artifact reference.

The authoritative executable definition is in `src/forgelab/domain.py`. JSON
examples emitted by the smoke run act as contract fixtures until versioned JSON
Schema generation is introduced.

A gate may be `PENDING` before a human decision, then `APPROVE`, `REJECT`, or
`REPAIR`. A pending record never authorizes promotion.
